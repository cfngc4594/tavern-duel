# Original card Resources

Generated by Tools/prepare_card_assets.py. Run the script with --validate-only for graph/source checks.

card_assets.json is JsonUtility-compatible: arrays of records, no dictionaries or jagged arrays. All Unity identifiers are strings. Every source GameObject transform is retained; only selected normal MeshRenderers are created. Only the root placement translation is reset at runtime. UV coordinates and triangle winding are native Unity, and PNGs are copied without vertical flips. Unity imports them as uncompressed ordinary Texture2D assets. Portrait slots come from original Actor bindings.

Profiles: minion_in_hand, spell_in_hand, minion_in_play, hero_in_play, hero_power, deck_25, deck_50, deck_75, deck_full, card_back. The derived card_back keeps the original hand base mesh with back in material slot 1; face its negative-Y side toward the camera through a placement parent.

API (HearthstoneDesktop.Presentation): OriginalAssetLoader.LoadCard(profile, optionalPortrait). Get OriginalCardView from the returned root; call SetPortrait, SetLabels, SetStats, SetStat, FindSourceNode, or GetWorldBounds. SetReadyHighlight(bool) accepts caller-computed legal-action eligibility; SupportsReadyHighlight reports whether the profile has a usable verified silhouette. Unsupported profiles remain neutral. LoadPortrait(cardId) returns the separately source-proven art.

Source frame/geometry: current official Blizzard client 37.0.0.255130.254477, Unity 6000.3.11f1, verified CDN bundle hashes in provenance.json. Neutral minion and Mage spell main-texture overrides follow normal_selection.json. Historical game values are not supplied by these current assets.

Portraits: existing community-hosted original-art derivatives, identity matched to historical 5834; their original resize/recompression and unversioned-source limitations are preserved in provenance.json. No generated backgrounds, baked card image, screenshot crop or baked shadow is used.

Generic frame/portrait shaders are independent built-in-pipeline compatibility implementations, NOT blanket Blizzard shader parity. Gem materials use a selected same-build Metal translation: MainTex alpha masks scrolling color and is never coverage; the original pass is opaque. gem_shader_evidence.json retains exact source blend/depth state and vertex/fragment code. Built-in light/SH globals replace URP lighting globals. Source-enabled hero/power static shadows use source-verified Metal blend/formulas in separate shaders. Source materials, shader references and extra fields remain in JSON. Vertex colors are preserved but not multiplied without verified shader semantics. TextMesh substitutes for proprietary UberText at its original anchors; Latin uses exact serialized original font IDs and Chinese uses source client BlizzardGlobal. Compatibility outlines have explicit sorting order below their fill to avoid oblique transparent-sorting overdraw. Exact locale substitution, curved-text and texture-rendering parity is not claimed. shadow_source_evidence.json, shadow_shader_evidence.json and projected_shadow_bindings.json retain the evidence and remaining runtime-binding gap.

Readiness: exact original green material/plane and static silhouettes for minion_in_hand, spell_in_hand and hero_power. Dynamic minion_in_play stays neutral: its original multi-pass compositor and tag selection are recovered, but required Grey/White fixed-pass shader constants are absent from bounded source, so no guessed silhouette is rendered. Hero/back/decks remain neutral. Highlight equations are translated from bundled Metal; local seconds supply the unrecovered _ShaderTime clock, so exact timing parity is not asserted. Source masks and flare keep their original Repeat samplers, one mip, and raw pixels. UberText enum metadata is recorded in ubertext_anchor_constants.json; Middle/Center values1/1 are verified.
