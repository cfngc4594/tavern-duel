# 同版本原客户端音频资源

本目录的音频来自公开 Blizzard CDN 的《炉石传说》客户端 **37.0.0.255130.254477**。卡牌与声音的关联不是由文件名猜测，而是由同版本 `CardDef → 效果预制体/状态动作 → AudioSource → SoundDef → AudioClip` 的序列化引用恢复。

- 中文台词由同版本 `asset_manifest_zhcn` 的 `baseGuid → guid` 映射选择。没有语言覆盖的角色音效标为 `global`，不冒称中文台词。
- 原压缩样本是 Unity AudioClip 内的 FSB5。WAV 使用 UnityPy 1.25.4 / fmod_toolkit 0.1.3 完整解码。保留原声道数与采样率，没有裁切、混音、归一化、变调或重新采样。
- 每个 WAV 与原压缩样本的 SHA-256、采样率、声道、样本数，以及卡牌/状态/资源引用见同目录机器可读 provenance JSON。
- 下载链验证了 install 内容键、encoding 页面 MD5、所用 CDN archive index 的 footer/目录/页校验、精确 HTTP Range，以及 BLTE 内容/编码/分块 MD5。
- 同版本的原始音量、音高、类别和停止状态保留为证据；Godot 中的时序适配与实际启用范围由运行时清单决定。证据中出现的禁用阶段、预施法、取消和英雄皮肤条件语音，不等于可在普通施法时无条件播放。

游戏规则采用历史卡牌数据，音源及绑定证据采用上述现代原客户端。**没有宣称这是 2014 客户端完全相同的采样、混音或逐帧时间。**
