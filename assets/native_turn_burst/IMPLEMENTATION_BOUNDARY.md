# v29.1 FX_Burst boundary

This is an executable compatibility simulation built from the recovered original particle modules, source mesh and texture, not the original Unity Shuriken engine. No painted replacement sprite was created.

Verified source: 80 particles at t0; random vertex selection on original 80-vertex mesh (placementMode0=Vertex); original normals; meshColor enabled but source color channel absent, white default. Emission transform quaternion(.5,-.5,.5,-.5), position(0,0,.079761505), Shape-only scale.1. Start lifetime .2–1, speed0–30, size.4–.85. Original min/max unweighted Hermite size curves use exact serialized times/slopes. Lifetime color white with linear alpha1→0. View-facing billboard, rotation0. Original material vertex=2*particleColor*_Color; main fragment=texture*vertexColor; pass SrcAlpha One. GlowIntensity0 disables the second pass. Original StarBurst1 texture, no generated particle artwork. Renderer maxParticleSize.5 is mapped to the application's orthographic viewport height (not a recovered original-client camera).

Godot PCG with explicit seed is a reproducibility aid, not Unity autoRandomSeed. Unity native clamp integration and writeback are not in managed code/source available here. Current compatibility policy is fixed1/60 total-speed excess damping with source dampen .3330105245, writing the correction into persistent velocity. VelocityOverLifetime is kept as a separate animated value re-evaluated each step; the exact native limit writeback channel is unverified. Drag is source0. Do not claim same per-particle trajectory or exact random sequence. References: https://docs.unity3d.com/cn/6000.0/ScriptReference/ParticleSystem.Particle-animatedVelocity.html and https://docs.unity3d.com/cn/6000.0/ScriptReference/ParticleSystem.Particle-totalVelocity.html .

Source simulationSpace is World. The sample expresses coordinates in the banner's fixed reference frame and the parent applies application screen animation. It is not a full Unity scene-space simulation. Size is not visually tuned; Shape-only scale affects spawn positions, not initial speed/size. The same ArrayMesh resource is rebuilt in place and shared by main/mask/shadow passes. Parent controls restart/advance/cancel and recursive _Color.a fade; no independent clone RNG.

API: setup(viewport,root) adds itself to root; restart(seed=-1); advance(delta); set_elapsed(t); cancel(); get_audit(). Test: tests/v29_1_burst_test.gd verifies seed reproducibility, 80 particles, lifetime completion, persistent mesh identity and cancellation. Headless tests do not replace GPU screenshots/scene integration QA.

Render padding correction: the 3200×1800 target retains 1250 pixels/localunit but is not a wider logical particle viewport. maxParticleSize stays mapped to the established logical 900×500/.72 view: height .4, cap .2 units.
