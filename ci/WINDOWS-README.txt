Tavern Duel - Windows x86_64 release

Extract the entire ZIP, then open TavernDuel.exe. Keep TavernDuel.pck beside it.
Requires Windows x86_64 and a Vulkan/Direct3D 12 capable GPU and current driver.
This uses the production main scene and Forward+ renderer. Automatic OpenGL
fallback is disabled; unsupported graphics devices will fail to start.

This independent build is unsigned. Windows may show an unknown-publisher warning.
Do not disable Windows security. Check the release source and SHA256SUMS first;
if your device policy blocks it, consult its administrator.

verification.json records the source commit and raw-asset verification.
SHA256SUMS contains checksums for the packaged files. Existing Android builds
and their data are unaffected. Performance varies with hardware.
